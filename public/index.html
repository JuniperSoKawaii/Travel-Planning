Travel Planning

      Claude can plan days, fix conflicts and suggest places by editing this trip directly. It runs on your own Anthropic account, so it needs an API key from the Claude Console. Usage is billed to that account.

      The key is stored only in this browser and sent only to Anthropic. It is not included in exported backups. Avoid saving it on a shared computer.

      Try "Plan a relaxed Saturday in Lisbon", "Fix my conflicts", or "Find a lunch spot near the museum". You can attach booking confirmations, tickets or screenshots with the + button. Claude sees this trip and changes it as you watch.
